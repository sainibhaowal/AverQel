# Brand assets

This directory contains AverQel's brand artwork and an older DeepSpace design
concept. The concept files are archived notes; they do not describe current
backend capabilities or approved public product claims.

For current product behavior, read the [in-app product documentation](../../frontend/app/documentation/page.tsx),
[backend documentation index](../../backend/docs/README.md), and
[DeepSpace implementation guide](../../backend/docs/deepspace/04-deepspace-agent-runtime.md).
For the readme banner and logo artwork, use the SVG and image files in this
directory and in [`../../Docs/brand/`](../../Docs/brand/).
