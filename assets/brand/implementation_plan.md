# Archived Agent Studio concept

> **Status: historical proposal, not an implemented feature specification.**

This file preserves an older proposal for an Agent Studio and live execution
graph inside a Proactive Workspace. The proposal refers to routes and
components that are not part of the current product contract. Do not use it to
infer that DeepSpace has multi-agent DAG orchestration, subagent spawning, an
Agent Studio, background email/calendar sweeps, or a live execution graph.

The current DeepSpace behavior and its limits are documented in the
[product guide](../../frontend/app/documentation/deepspace/page.tsx),
[runtime implementation guide](../../backend/docs/deepspace/04-deepspace-agent-runtime.md),
and [backend documentation index](../../backend/docs/README.md). New work
should begin from those guides and verified current routes.
