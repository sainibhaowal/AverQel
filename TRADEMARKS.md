# AverQel Trademark and Brand Policy

This policy explains how the AverQel name and official product identity may be
used with the open-source AverQel software.

## What is protected

The following identify the official AverQel project and product:

- the name `AverQel`;
- the AverQel wordmark, logos, and icons;
- the official AverQel desktop application name and visual identity; and
- names, artwork, and other marks identified as official AverQel branding.

These are project brand identifiers and may be unregistered trademarks. This
policy does not claim that any mark is registered.

## Code license and brand rights are separate

The AverQel source code is available under the [Apache License 2.0](LICENSE).
That license permits use, modification, and redistribution of the code under
its terms. It does not grant permission to use AverQel trademarks, logos,
icons, or official product identity in a way that suggests an unofficial
version is an official AverQel release.

Copyright, license, attribution, and third-party notices must remain with any
redistribution as required by the Apache License 2.0.

## Acceptable use

You may:

- refer to AverQel accurately when discussing or linking to the upstream
  project;
- redistribute an unmodified AverQel release while preserving its notices and
  identifying it accurately; and
- describe a product as “based on AverQel” when that description is truthful
  and does not imply sponsorship or endorsement.

## Forks and modified distributions

Modified versions should use a different product name, application name,
package identifier, domain, logo, icon, and visual identity. Do not distribute
a modified version as an official AverQel build or use the AverQel branding as
the primary identity of a competing product or service.

A fork may retain a factual statement such as “based on AverQel” and should
link to the upstream project. It must not imply that the AverQel project
endorses, sponsors, or maintains the fork.

This policy does not restrict truthful, nominative, or other uses permitted by
applicable law.

## Official releases

Official AverQel releases are published through the AverQel project’s official
GitHub repository, release channels, and website. A third-party build must not
use the official name or branding in a way that makes users believe it came
from those channels.

Questions about brand use should be opened as a private contact request to the
project maintainers before distributing a product that uses AverQel branding.
